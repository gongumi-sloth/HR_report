## 0. 전체 페이지 구성
- 1p 종합결과 / 2p 검증 포인트 / 3p 자기소개서 분석 / 4p~ BP 평가 상세
- **1p, 2p는 페이지 고정. 3p부터는 콘텐츠 내용에 따라 페이지 수 유동적.**

## 1. header / footer
- header: 채용 공고명(채널명) / 지원자명 / 응시번호
- footer: 제품명·로고 / 저작권 명시 / 마지막 페이지 하단 저작권 안내

## 2. 응시자 정보 영역
- 출력: 채용 공고명(채널명), 직무, 이름, 응시번호, 평가일
- 응시자 사진 없음(서류 전형). **'프리즘 서류평가'는 고정 텍스트.**

## 3. (main contents 1) 종합요약

### 3-1. 종합요약
| 구성요소 | 규칙 | 예시 |
|---|---|---|
| 종합점수 | **소수점 둘째자리** | 82.21 |
| 직군 내 상위 % | 비교집단: 공채형=해당 전형 전체 / 수시형=준거집단 | 영업직 상위 38% |
| 합불 여부 | 접수 단계 부적격 기준에 따름. **두 기준 중 하나만 적용. 접수에서 미선택 시 결과지에도 표현하지 않음.** ①n배수 기준: '3배수 이내'/'3배수 미달' ②점수 기준: '권장(50점 이상)'/'검토 필요(50점 미만)'. AI기본법상 적격/부적격 표현 회피(대안: 추천/보류, 권장/검토 필요) | 3배수 이내 |
| 한 줄 코멘트 | 강점+단점+채용담당자 액션, 두괄식 최상단 | 현장 중심의 공학 경험은 풍부하나, 조직 역량에 대한 근거가 부족하여 추가 검증이 필요합니다. |
| 상세 코멘트 | 자소서 주요 내용 요약(PAC 특장점 요약 API), 불릿 | 예시 4개 불릿 |
| 종합 그래프 | 막대 안에: 지원자 점수(100점 만점) / 합불 기준점수(**선택 시만**) / 동일 직무 평균 / 상위 10% 점수 | — |

### 3-2. BP 역량별 점수 (직무적합도·조직적합도·지원동기)
- 타이틀 'BP 역량별 점수'는 결과지에서 제거 (2026-05-27)
- 각 영역: 점수 / 동일 직무 평균 / 상위 10% 점수 / **직무 평균 대비 점수차(±p)**
- **평균 미만 → 부정적 하이라이팅 / 상위 10% 이상 → 긍정적 하이라이팅**
- 직무적합도 하위 메트릭: 직무경험·직무동기·직무지식·직무역량(+역량분자 등급)
- 직무적합도 영역에 하드스킬 검출 내용 포함(확인/미확인 각각)
- **레이아웃 가변성: 각 메트릭·프로파일 영역은 가변적 — 한 영역이 없으면 다른 영역이 확장되어 완성도 유지**
- (보류) 하드스킬 매칭의 점수 반영은 이번 프로젝트 범위 외

### 3-3. 응답 완성도 (답변적합도·구체성·자기소개)
- 타이틀 '응답 완성도'는 결과지에서 제거 (2026-05-27)
- 점수 + **점수 구간별 룰 베이스 근거 문장**(AI 호출 없음, 사전 정의 텍스트)
  - 참조: 「프리즘 결과지 4.2 개발 - BP 답변적합도/구체성/본인소개 매트릭별 근거 내용」 SDS r7
- **40점 미만일 경우 부정적 의미의 하이라이팅(디자인)** ← '주의' 배지 조건

### 3-4. 자기소개서 분석 프로파일 (스파이더 차트)
- 이름 변경: 역량 프로파일 → 자기소개서 분석 프로파일
- 6개 메트릭 점수 + 메트릭별 동일 직무 평균
- 범례: ①지원자 ②**직무별 평균**

### 3-5. 검증 포인트 (2p)
- **강점(심화 검증)**: factor 기준 **상위 2개** 항목 / **검토(추가 검증)**: 하위 2개 항목
- factor 후보: 직무경험·직무지식·직무동기(직무적합도), 직무역량의 각 역량분자, 조직적합도의 각 역량분자, 직무동기·회사동기(지원동기), 답변적합도, 구체성, 본인소개
- 우선순위: 동일 등급 중 가중치 높은 것 → 동일 가중치면 직무역량 역량분자 → 직무경험 → 직무지식 → 직무동기 → 조직적합도 역량분자 → 직무동기 → 회사동기 → 답변적합도 → 구체성 → 본인소개
- 각 항목: 상위/하위 % + 한줄 근거 코멘트(근거문장 요약 API; 답변적합도·구체성·본인소개는 룰 베이스) + 면접 연계 질문
- **근거 문장이 없는 경우(검토 카드): '해당 역량을 확인할 수 없음'** + 해당 역량 확인용 면접 질문 추천
- 강점 카드에 확인된 하드스킬 / 검토 카드에 미확인 하드스킬
- 문항별 검사 결과: 문항별 답변적합도 점수 + AI 작성 의심 비율(GPK 탐지)

## 4. (main contents 2) 자기소개서 분석 (3p~)
- [문항 + 답변] 원본 보기 역할
- 문항 표기: "문항 1 · {질문 원문}"
- 답변: 원문 + 메트릭 근거문장 하이라이팅(**메트릭 구분 없이 동일 하이라이팅**) + GPK 의심 문장 밑줄
- 검출 내용(답변 하단): 확인된 역량(메트릭·등급), 검출된 역량분자(하이라이팅 없음), AI 작성 의심 비율 %
- BP 검사 시 GPK 필수 동시 검사

## 5. (Appendix) BP 평가 상세 (4p~)
- 설명가능성 파트. 평가 요소별 결과+근거 상세
- 직무적합도: 점수 / 직무경험·직무지식·직무동기 각 등급+근거요약+**근거문장(일련번호+자소서 문장)** / 직무역량(역량분자, **커스텀 가능 — BP 4.1 기능**)
- 조직적합도: 점수 / 역량분자(커스텀 가능)
- 지원동기: 점수 / 회사동기·직무동기
- 답변적합도·구체성·본인소개: 점수 + 점수 구간별 룰 베이스 텍스트
- 하드스킬: 항목 / 검출 여부 / 근거 요약+근거 문장

## ⚠️ 현 샘플 구현과의 차이/시사점 (2026-06-13 확인)

1. **3p(자기소개서 분석)도 페이지 유동적** — SDS: "3p부터 유동적". 현 구현은 P3 고정 1페이지(문항 3개 기준). 문항 수·답변 길이가 늘면 대응 필요.
2. **레이아웃 가변성** — 영역(메트릭) 부재 시 다른 영역 확장. 현 템플릿은 홍길동 데이터 형태 고정.
3. **조건부 표시 규칙 확보**: 합불 배지(접수 미선택 시 미표시, 문구 2모드), 평균 미만/상위10% 하이라이팅, **40점 미만 '주의'**(본인소개 36.82 배지의 근거).
4. **레이더 범례 명칭**: SDS '직무별 평균' vs 현 구현·Figma '평균' — Figma 디자인 고정 원칙과 충돌 시 사용자 확인 필요.
5. **빈 항목 문구 3종 구분**: P2 검토 카드 '해당 역량을 확인할 수 없음' / P4+ 세부항목 '확인된 자기소개서 근거 문장이 없습니다.'(§8-2-2) / 하드스킬 '관련 근거 문장 없음.'
6. **점수 소수 둘째자리** 공식 확인(§4-G 해소). **비교집단 정의** 공식 확인(공채형=전형 전체, §4-B 해소).
7. 역량분자는 **고객사 커스텀 가능** — §4-C의 "한일시멘트 사용 항목 set 확인" 질문이 SDS로도 뒷받침됨.
