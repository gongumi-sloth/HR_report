# 프리즘 4.2 — 프리즘 접수 화면 기능 개발 SDS (개정 2026-06-29)

> 본 개정본은 2026-06-29 접수 화면 목업 수정분을 반영한다.
> 대상 목업: `admin/prism-admin-request-info-20260629.html`(프리즘워크), `admin/prism-bridge-request-info-20260629.html`(프리즘브릿지)
> 변경/추가 항목은 **[변경]·[추가]** 로 표기한다.

---

## 1. 개요
- BP평가에 추가되는 콘텐츠 중 접수 단계에서 처리해야 하는 기능과 화면을 정의한다.
- 전형 통과 기준 영역을 분리한다.
- 직무기술서 파일 업로드 기능을 RP매칭과 공유한다.
- 프리즘워크와 프리즘브릿지 모두에 해당한다.

---

## 2. 접수 단계에 추가/변경하는 기능

### 2-1. 등록 자소서 유형 선택
- 벌크형·단건형 설명 영역 하단에 안내 문구 추가:
  - **[변경]** `※ 직무별 평가 비교군이 10명 이하일 경우 BP평가에서 '상위 10% 비교' 정보가 제공되지 않습니다.`
- ※ 프리즘워크 접수 화면 기준. 프리즘브릿지에는 자소서 유형 선택 영역이 없어 미해당.

### 2-2. BP평가
- 버전 선택: `BP평가 v2` 라디오 항목 제거 → **v3 / v4** 만 노출 (2026/06/11 회의 요구사항)
- **[추가] BP평가 `v3` 선택 시 직무기술서 첨부 영역을 출력하지 않는다** (v4 선택 시 출력)
  - 프리즘워크: BP평가가 v3이면 직무기술서 섹션 미출력. 단 BP v4 또는 RP매칭을 선택하면 출력한다.
  - 프리즘브릿지: BP평가가 v3이면 공통 직무기술서 섹션 미출력, v4 선택 시 출력한다.

### 2-3. 전형 통과 기준 (영역 분리)
- 전형 통과 기준 설정 영역을 BP평가·RP매칭과 동일 레벨의 **별도 영역으로 분리**한다(직무기술서 첨부 영역 위에 배치).
- 전형 통과 기준은 프리즘 종합점수를 기준으로 결과를 산출한다(BP평가 단독 선택 시 BP평가 점수 기준).
- **[변경] '사용 안 함 / 사용함' 라디오 버튼 제거.**
- **[변경] '점수 기준' 제거 → '배수 기준'만 운영.**
- 구성:
  - `☐ 배수 기준` (체크박스) — 체크 시 적용, 미체크 시 미적용(숫자 입력칸 비활성화). **기본값: 미체크.**
  - `모집인원 (   )명  |  (   ) 배수 미만 시 검토 필요`
- (안내) BP평가를 포함해 2개 이상의 평가를 선택하여, **모든 평가 결과를 기준으로 판정**합니다. (BP평가 포함 2종 이상 선택 시 노출)
- 숫자 입력란은 숫자 이외의 문자·기호 입력 불가. 숫자만 가능.

#### 전형 통과 기준 툴팁 — **[변경] 점수 기준 제거에 맞춰 간소화**
```
[전형 통과 판단 기준]
· 배수 기준 : 점수 순위가 (모집인원 × 배수)에 들지 못한 경우 '검토 필요'
· 체크 시 적용 / 미체크 시 전형 통과 여부 미적용
· 결과지 표기 : 기준 충족 시 '권장', 미달 시 '검토 필요'
```

#### 결과지 표현 방식 — **[변경] 점수 기준 표기 삭제**
- **BP평가 포함 복수 라이선스**: 종합결과 상단에 **배수 기준** 판정을 옵션에 따라 표기.
  - BP평가 자체에는 전형 통과 여부 표현 없이 직무 상위 n%만 표현.
  - 지원자에 대한 평가는 BP평가 첫 페이지에서 상위 10% 비교치·평균 비교치 막대그래프로 충분히 해소됨.
- **BP평가 단독**: BP평가에 **배수 기준** 판정을 옵션에 따라 표기.

### 2-4. 직무기술서(JD 또는 채용공고) 파일 업로드
- 검사 항목에서 BP평가 또는 RP매칭을 선택할 경우 직무기술서(JD/채용공고) 파일 업로드 영역 활성화.
  - 둘 중 하나만 선택해도 활성화된다.
  - **[추가 단서]** BP평가 v3 단독 선택 시에는 미출력한다(2-2 참조).
- 필수 기능이다(반드시 업로드해야 함).
- 직무기술서 첨부 기능 — RP매칭 직무기술서 영역과 같이 **테이블 형태**로 구현:
  - `[파일 추가]`: 클릭 시 파일 탐색기 출력
  - 파일 업로드 전: 파일명 자리에 `등록된 파일이 없습니다.` 메시지 출력
  - 파일 선택 후: 파일명·파일크기·삭제 버튼 출력
  - 파일당 최대 3MB, 전체 10MB로 용량 제한
  - 동일 파일명 중복 불가 (동일 파일명 업로드 시 모달 출력)
- 안내 메시지:
  `※ 하드스킬 평가(BP평가)·직무 매칭(RP매칭)을 위해 JD 또는 채용공고 파일을 등록해주세요. (PDF, 한글(hwp, hwpx), MS워드(docx, doc) / 파일당 최대 3MB · 총 10MB · 동일 파일명 중복 불가)`
- BP평가 또는 RP매칭을 선택하고 직무기술서를 업로드한 뒤, 이후 다시 선택 해제하고 검사요청서를 제출하면 업로드한 파일은 소실되는 것으로 한다.
- (참고) 이후 JD에서 하드스킬을 추출하는 과정: 최고운, 「프리즘 결과지 4.2 개발 - 하드스킬 추출 워크플로우 정의」, SDS, r15, 2026-06-15.

### 2-5. RP매칭 — 부적격 기준 설정 UI 변경
- **[변경] BP평가 전형 통과 기준과 동일한 방식으로 변경.**
- **[변경] '사용 안 함' 라디오 제거 → '점수 기준' 단일 체크박스.**
  - `☐ 점수 기준` (체크박스) — 체크 시 적용, 미체크 시 미적용(입력칸 비활성화). **기본값: 미체크.**
  - `(   )점 미만 부적격   ※ 0 ~ 100 사이의 수만 입력`
- 숫자 입력란은 숫자 이외의 문자·기호 입력 불가. 숫자만 가능.
- ※ 프리즘브릿지의 RP매칭은 안내 문구만 제공하므로 부적격 기준 컨트롤이 없다.

## 부록. 2026-06-29 반영 결정 사항
1. 전형 통과 기준에서 '점수 기준' 및 '사용 안 함/사용함' 라디오 제거 → 배수 기준 단일(체크박스 토글). 툴팁·결과지 표현의 점수 기준 서술도 삭제.
2. RP매칭 부적격 기준 임계치 표현은 `( )점 미만`(미만) 유지.
3. RP매칭 부적격 기준 결과 표현은 `부적격`(검토 필요로 순화하지 않음) 유지.
