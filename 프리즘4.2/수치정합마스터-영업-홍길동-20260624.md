## 1. 정합 규칙 (SDS 근거 — 절대 기준)

### 1-1. 라이선스 개수 → 페이지 구성 (종합결과 SDS §5)
- **라이선스 2개 이상 사용** → 종합결과 페이지 사용. 본 건은 결함·표절·블라인드·GPK·BP **다수 라이선스**이므로 종합결과 페이지 **필수**.
  - 종합결과 페이지 **상단에만** 응시자 정보. **각 라이선스 결과지 상단엔 응시자 정보 미표시.**
  - 종합결과 = 판정 + 각 라이선스 요약, **1페이지 초과 금지.**

### 1-2. 라이선스별 부적격(=배지 '검토 필요') 기준
| 라이선스 | 부적격 기준 (개별 결과지, SDS p3) | 종합결과 table 각주(SDS p2) | 채택 |
|----------|-----------------------------------|------------------------------|------|
| 결함검사 | 중대결함 2개 이상 **또는** 의심결함 5개 이상 | 중대 1개 이상/의심 3개 이상 | `[확인]` 두 기준 상이 — 사용자 확정 필요 |
| 표절검사 | 전체 표절률 30% 이상 **또는** 문항표절률 50% 이상 | 동일 | 개별=종합 일치 ✓ |
| 블라인드 | 중대위반 2개 이상 **또는** 의심위반 5개 이상 | 중대위반 3개 이상 | `[확인]` 상이 — 확정 필요 |
| BP평가(점수) | 권장 50점 이상 / 검토 필요 50점 미만 | CLAUDE.md 디자인시스템 | ✓ |
| 종합(n배수) | n배수 이내 / n배수 미달 (접수 선택 시) | SDS §3 | 둘 중 1택 |

> **합불 배지는 접수에서 ①n배수 ②점수 중 택1. 미선택 시 결과지에 미표시.** (SDS, CLAUDE.md)

### 1-3. 표기 포맷 (실데이터 필수 규칙)
- **결함·블라인드 = 개수**(중대 N개 / 의심 N개 / 참고 N개). **%로 표기 금지.**
- **표절 = 비율(%)**, 소수 둘째자리. **전체 표절률 = 문항별의 집계** (전체 ≥ max(문항) 불가능한 값 금지).
- **GPK = 문항별 탐지/미탐지 (이진)** + 탐지 N문항/전체. (% 미확보 — CLAUDE.md CH-033)
- **점수 = 소수 둘째자리** (BP 6메트릭·종합·BP평가점수). 숫자는 Noto Sans(`.num`).
- 결함/표절/블라인드 **상세 본문은 통합본문 사용 시 개별 페이지에서 노출 안 함** (통합본문에서 하이라이팅).

### 1-4. 파생·조건부 표시 (build_reports.py + BP SDS)
- 답변적합도·구체성·본인소개 코멘트 = **점수 구간 룰베이스 자동선택**(AI 호출 없음). 점수만 정하면 문구 결정.
- **본인소개 40점 미만 → '주의' 배지.**
- BP 메트릭: **평균 미만 → 부정 하이라이팅 / 상위 10% 이상 → 긍정 하이라이팅.**
- 검증포인트: factor 기준 **강점=상위 2개 / 검토=하위 2개.** 근거문장 없으면 "해당 역량을 확인할 수 없음".
- BP평가 점수 = **6개 메트릭 평균** (현 Figma 90.02 ≈ 6평균 ≈ 89.5와 동일한 내부규칙 유지).
