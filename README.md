# HR_report
결과지 목업 제작용

---

## 프로토타입 열람 가이드

### 페이지 이동 버튼에 대하여

HTML 프로토타입 파일을 브라우저에서 열면 최상단에 **[◀ 이전 / 다음 ▶]** 버튼 영역이 표시됩니다.

이 버튼은 **목업 전용 UI**입니다.

- 결과지는 A4 다중 페이지 구조로, HTML 파일 하나에 전체 페이지가 담겨 있습니다.
- 브라우저에서 페이지를 한 장씩 확인할 수 있도록 목업에만 추가된 내비게이션입니다.
- **실제 구현(PDF 출력 또는 서버 렌더링) 시에는 이 버튼이 출력되지 않습니다.**

열람 시 해당 버튼은 무시하고 결과지 본문 영역만 검토하시면 됩니다.
