## 1. 목적과 범위

- **목적**: 임의의 자소서를 *접수 → 분석 → 결과지 출력*까지 실제로 돌려, **기획(SDS·Figma)대로 구현됐는지** 확인하는 기능 QC.
- **범위**: PDF·엑셀 결과지 / 프리즘 **전 라이선스** 결과지 포함.
- **범위 밖**:
  - 웹 결과지(이번 프로젝트 범위 아님)
  - AI가 매긴 **점수의 정확도**(= 모델 품질). 우리는 그 점수가 *결과지에 일관되게·기획대로 표현되는지*만 본다.
  - 표절·GPK(GPT Killer) 검출 **엔진 성능**. 의도 주입이 어려우므로 GPK는 'AI 작성률 %'가 *표기되는지*만 확인(값의 정확도는 평가 안 함).

## 3. E2E 단계 (자소서마다 1바퀴씩)

| **0. 준비** | 자소서 + 채용공고/JD + 직무기술서(하드스킬 키워드) 세팅 | 입력물 구비 | — |

| **3. 결과 확인·관리** | 어드민/매니저에서 콘텐츠 확인·수정·재생성, 근거요약 QC, 하드스킬 재매칭 | 관리 기능 동작 · **여기 표시값이 결과지 대조의 기준점** | 어드민(근거요약QC·매니저·하드스킬·BP설정·자료생성) |

## 4. 결과지 검증 4기준 (한일시멘트 JSON 대조가 아님)

1. **3단계 분석값과 일치** — 같은 점수·등급·근거문장이 결과지에 그대로 표시
2. **Figma/SDS 레이아웃·콘텐츠대로** — 단일/복수 라이선스 구성, A4 규격, 고정문구(저작권·AI 고지)
3. **AI 콘텐츠 근거성·금지어** — 자소서에 있는 내용만 인용, '합격/불합격/적격/부적격' 등 금지어 없음
4. **표시값 내부 일관성** — 종합점수가 결과지 내 여러 위치에서 동일 등

## 5. 라이선스·옵션 커버리지 + 시나리오

**라이선스(검사 종) 8종**: 결함검사 · 표절검사 · GPK · 블라인드 · BP평가 · 프리즘Q · PAC · RP. (BP는 4.0만 검증)

**옵션 3축** (접수·다운로드 설정 — 같은 자소서로 설정만 바꿔 테스트):
- **라이선스 조합**: 단독(예 BP 단독, 종합결과 없음·상단 응시자정보) / 복수(2종+, 종합결과 페이지 생성)
- **전형통과 기준**: 점수기준(권장/검토 필요) / 배수기준 / 사용 안 함. *비교·판정 기준집단 = 근거집단(회사 집단평균점수)*
- **통합본문**: ON(선택 검사 출처를 자소서 1부에 통합·개별 본문 제거) / OFF. 대상 = 본문 마킹 6종(결함·표절·블라인드·GPK·BP·RP)

**대표 시나리오 7개** (워크북 `시나리오` 시트 — 옵션 조합 + 작업자 분배·진행):

| | 라이선스 | 전형통과 | 통합본문 | 샘플 |
|---|---|---|:--:|:--:|
| **SC-1** | BP 단독 | 점수→권장 | OFF | B |
| **SC-2** | BP 단독 | 점수→검토 필요 | OFF | C |
| **SC-3** | BP 단독 | 배수 | OFF | A |
| **SC-4** | BP+표절+블라인드 | 점수 | ON | A |
| **SC-5** | 전체 8종 | 배수 | ON | A |
| **SC-6** | BP+GPK | 사용 안 함 | OFF | A |
| **SC-7** | 결함+표절(비-BP) | — | ON | A |

→ 단독/복수 · 점수/배수/미사용 · 통합본문 ON/OFF가 모두 걸림. 표절·GPK는 엔진 의존이라 '걸리면 표현(AI 작성률 % 등)만 확인'.

## 7. 진행·보고

- **우선순위**: P1(릴리즈 블로커) 먼저. 미구현 단계의 TC는 삭제 말고 **Blocked**로 둔다(구현되면 재실행).
- **시작 기준**: 단계별 스모크(기본 동작) 통과 시 QC 투입(반쯤 만든 화면에 결함 무더기 쌓는 것 방지).
- **종료(릴리즈) 기준**: P1 전부 Pass + 치명 결함 0.
- **결함 보고**: **워크북 시트에 직접 기록 — 이 워크북이 QC 기준 문서.** P1·치명은 즉시 PM 에스컬레이션. 매일 아침 10분 트리아지로 Blocked→testable 전환.

## 8. 작업 분배 · 검수자 작업 흐름

- **공통 vs 시나리오 구분**: TC는 워크북 `[구분]` 컬럼으로 갈림 — **공통**(시나리오 무관, 한 번만 검증, 약 191건) / **시나리오-의존**(옵션마다 다름, 약 39건). 공통은 GPK·복수 포함 baseline에서 1회.
- **작업 분배**: **작업자N = SC-N**. TC `[담당]` 컬럼에 작업자1~7 분배(시나리오-의존=해당 시나리오 / 공통=나눠서). 검수자는 **`[담당]`=내 작업자N 필터 → 내 것만** 봄(아무도 230개 전부 안 봄).
- **진행 집계**: `시나리오` 시트에 작업자별 **분배/완료/남은** 자동 수식(완료=QC결과 입력된 행) + 합계. 가이드 대시보드(시트별·우선순위별·결함)도 자동.
- **검수자 1·2단계**: ① 본인 시트에서 `[담당]` 필터 → ② (시나리오 담당이면) `시나리오` 시트의 옵션대로 셋업 → 실행 → QC결과 기입.
