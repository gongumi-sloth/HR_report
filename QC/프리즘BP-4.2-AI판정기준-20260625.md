# 프리즘 BP 4.2 — AI 출력 판정 기준 (QC용)

> 작성 2026-06-25 · PM 최고운
> AI 출력(한 줄 코멘트·자소서 특장점·하드스킬 추출·하드스킬 검출)은 **돌릴 때마다 문장이 달라진다.**
> 따라서 '예시와 글자가 같은가'가 아니라 **'SDS 가드레일을 지켰는가'**로 판정한다.

## 판정 원칙 (이번 QC)

- **객관적으로 확인 가능한 가드레일만 본다** — 세거나 · 단어를 찾거나 · 형식·필드를 확인하면 끝나는 것.
- **정성적 판단은 이번 QC에서 제외** — '이게 진짜 하드스킬인가', '근거가 타당한가', '어조가 적절한가', '의미가 중복인가' 같은 **가치판단은 보지 않는다.**
- 하드 룰(금지어 등) 위반 = **즉시 Fail** / 개수·글자수·형식 위반 = 결함 / 정성 항목 = **N/A(이번 제외)**.

---

## A. 공통 — 모든 AI 출력

| 본다 (객관) | 판정 |
|---|---|
| **금지어 없음**: 합격·불합격·적격·부적격·탈락 (AI기본법 — '권장/검토 필요'로 표현) | 하나라도 있으면 **Fail** |
| 정상 호출 시 `status=ok`, required 필드 모두 존재 | 누락 시 Fail |
| 변수 누락 호출 시 `status=fail` 반환(빈 값으로 진행하지 않음) | 빈 값 진행 시 Fail |

## B. 출력별 — 객관 체크

| 출력 | 본다 (객관) |
|---|---|
| **한 줄 코멘트** | 1문장 · 90자 이내 · parts(강점/보완/액션) 필드 존재 · 상위%·총점 **숫자 미포함** |
| **자소서 특장점** | **4~5개** · 마크업(`#`, `**`, `①②`)·번호 없음 |
| **하드스킬 추출** | **5~7개** · category 값이 `tool_based / method_based / knowledge_based` 만 · 각 항목 `detection_criteria` 필드 존재 |
| **하드스킬 검출** | key별 evidence **1~5개** · offset(bodyIndex/beginOffset/endOffset) 반환 · score 기준 검출/미검출 표시 |

## C. 이번 QC에서 보지 않는 것 (정성 → N/A)

- 무근거 생성 여부(grounded) — 본문과 대조해 사실 여부 판단
- **하드스킬이 맞는가 / 소프트스킬이 섞였는가** — 가치판단
- 자소서 특장점의 가치판단어·의미 중복 여부
- 한 줄 코멘트의 두괄식 구조·어조 적절성, 검토 메트릭 롤업 서술
- 하드스킬 검출 근거의 타당성·피상 매칭 배제 여부

→ 위 항목은 SDS 객관 가드레일을 넘는 '품질 판단'이라 **이번 QC 범위 밖**.

---

## 요약

- **본다(객관, 위반 시 Fail)**: 금지어 · 개수 · 글자수 · 형식(마크업/번호) · 필드/스키마 · 범주 값
- **안 본다(정성, N/A)**: 품질 · 타당성 · 하드스킬 여부 · 중복 · 어조
