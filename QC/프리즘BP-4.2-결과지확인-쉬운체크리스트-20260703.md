# 결과지 확인 체크리스트 (그대로 따라 하기)

> 작성 2026-07-03 · 전제: 검사방 1개에 3개 직무 × 4명 접수·검사 완료 상태
> 방법: 매니저 → 결과지 노출 항목에서 평가를 켜고 끄면서 결과지만 확인 (STEP 3 전까지 접수 추가 없음)

## 🔁 매번 똑같이 보는 3가지

> 1. **켠 항목만 나온다** — 안 켠 평가 이름이 결과지 어디에도 보이면 안 됨
> 2. **종합결과** — 2개 이상 켰으면 있어야 하고, 1개만 켰으면 없어야 함
> 3. **상위 10%** — BP를 켰을 때만 나올 수 있음. BP 안 켰는데 보이면 버그

## STEP 1. 하나씩만 켜고 확인 (7번)

| 완료 | 켤 항목 | 열어볼 결과지 | 추가로 볼 것 |
|:---:|---|---|---|
| ☐ | 결함검사만 | 홍길동(영업) | 결함 3건: "무하우" / 같은 문장 2번 / "되겟습니다" |
| ☐ | 표절만 | 홍길동 | 표절 섹션이 보이기만 하면 됨 (검출 0건이어도 정상) |
| ☐ | 블라인드만 | 김도윤(분석가) | "1998년생"과 "부산" 잡혔는지 |
| ☐ | GPK만 | 김도윤 | AI 작성률 OO% 숫자가 보이는지 |
| ☐ | BP만 | 이서연(영업) | 점수가 보이는지 (상위10%는 STEP 3에서) |
| ☐ | 프리즘Q만 | 정수민(마케터) | 본문에 형광펜 마킹이 **없어야** 함 |
| ☐ | PAC만 | 정수민 | 본문에 형광펜 마킹이 **없어야** 함 |

## STEP 2. 여러 개 켜고 확인 (4번)

| 완료 | 켤 항목 | 열어볼 결과지 | 추가로 볼 것 |
|:---:|---|---|---|
| ☐ | 결함+표절+블라인드+BP | 홍길동 | 종합결과 있어야 함 |
| ☐ | 표절+GPK+BP | 이서연 | 깨끗한 자소서라 검출 0건이어야 정상 |
| ☐ | GPK+BP+프리즘Q | 최민재(영업) | 마킹은 GPK·BP 것만 (Q는 마킹 없음) |
| ☐ | 7개 전부 | 홍길동 | 다 나오는지. STEP 4-⑤에서 다시 씀 |

## STEP 3. 상위 10% 확인 (여기서만 접수 추가)

- ☐ ① 지금 상태에서 BP 켜고 이서연 결과지 → 영업 4명뿐이라 상위 10% **없어야** 정상
- ☐ ② 영업 직무로 자소서 6건 추가 접수: 정수민, 김도윤, 강지우, 윤태현, 한소영, 임재현 (영업 10명 됨)
- ☐ ③ 검사 다시 돌리기
- ☐ ④ 이서연 결과지 다시 열기 → 상위 10% **있어야** 정상
- ☐ ⑤ 최민재 결과지 → 상위 10% **없어야** 정상

## STEP 4. BPv3 확인 (방 복사)

- ☐ ① 개발에 확인: "검사방 복사하면 접수된 자소서도 같이 복사되나요?"
  - 예 → 진행 / 아니오 → 복사한 방에 영업 자소서 10건 재접수
- ☐ ② 검사방 복사 → BP 버전 v3 → 검사 돌리기
- ☐ ③ BP만 켜고 이서연 → 점수 + 상위 10%
- ☐ ④ 결함+표절+블라인드+BP 켜고 홍길동 → 🔁 3가지
- ☐ ⑤ 7개 전부 켜고 홍길동 → STEP 2 마지막 결과지와 비교: BP 버전만 다르고 나머지 동일해야 함

## 버그로 기록할 것 (발견 시)

- 안 켠 평가가 결과지에 보인다
- 1개만 켰는데 종합결과가 있다 / 여러 개 켰는데 없다
- BP 안 켰는데 상위 10%가 보인다
- 프리즘Q·PAC 때문에 본문에 형광펜 마킹이 생겼다
