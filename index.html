무하유 HR 제품군 공통 결과지 디자인 시스템

이 시스템은 특정 제품이 아니라 무하유 HR 제품군 전체가 공유하는 결과지 규격입니다. 새 HR 제품이 나와도 이 시스템의 컴포넌트로 결과지를 조립하면 제품 간 패밀리 일관성이 유지되는 것을 목표로 합니다. 어느 한 제품에 종속되지 않습니다.

목적
제품이 늘어도 결과지의 위계·색·타이포·페이지 규격이 한 가족처럼 보이게 한다. 제품별로 새로 디자인하지 않고 공통 컴포넌트를 조립한다.
사용 대상
결과지를 기획·조립하는 기획자, 컴포넌트를 유지하는 디자이너, 실제 결과지를 구현하는 개발자. 읽는 순서: 절대원칙 → 파운데이션 → 컴포넌트 → 조립 가이드.

설계 원칙
  • 공통 골격은 실재한다 — 헤더·종합 결과 카드·종합 코멘트·푸터는 네 제품이 같은 슬롯을 공유합니다. 이것이 패밀리 시스템의 뼈대입니다.
  • 등급 언어는 슬롯 공통 · 표현 변형 — 같은 "종합 결과" 자리에 상/중/하(프리즘), 점수+S~D(몬스터), A/PASS(역량검사), 교차 유형(교차진단)이 각각 들어갑니다. 색·로고만으로 통합되지 않습니다.
  • 제품 고유 영역이 크다 — 몬스터의 레이더 차트, 역량검사의 직무/조직 적합도·부적응 지표, 교차진단의 교차 매트릭스는 다른 제품에 대응물이 없습니다. 이들은 공통화 대상이 아니라 제품 변형 컴포넌트로 시스템에 정식 등재해야 합니다.

절대원칙

모든 제품의 결과지에 예외 없이 적용됩니다. 위반 시 디자인 시스템 미준수로 간주합니다.

원칙 1
한 페이지는 반드시 A4 사이즈로 구현한다
.page { width: 990px; height: 1399px; overflow: hidden; page-break-after: always; }
@page { size: A4; margin: 0; }
* { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
min-height 사용 금지 · overflow: hidden 생략 불가
원칙 2
모든 페이지에 문서 헤더와 푸터가 들어간다
예외 페이지 없음. 헤더 27px · 푸터 34px 고정, flex-shrink: 0 필수. 지원자 카드(BP평가 header)는 1페이지에만 노출.
원칙 3
콘텐츠가 페이지 중간에 잘려서는 안 된다
콘텐츠 가용 높이 = 1399 − 헤더(27) − 푸터(34) − 상하 패딩(48) = 1290px.
평가 항목·문항 카드 블록 단위로 page-break-inside: avoid, 넘치면 블록째 다음 페이지로 이동. 안내사항 카드는 넘어가더라도 반드시 포함.
원칙 4
이 문서에 없는 색·크기·컴포넌트를 임의로 만들지 않는다
필요한 표현이 없으면 시스템에 컴포넌트를 먼저 추가한 뒤 사용합니다. 합격/불합격·적격/부적격의 직접 표현 금지(AI기본법) — 「n배수 이내/이상」 「권장/검토 필요」로만 표현하고, 항상 「권장 기준: …」 캡션을 병기.
원칙 5
지원자 이름은 마스킹한다
예: 홍*동. 지원번호는 마스킹 없이 표기.

페이지 템플릿 · 변형 규칙 프리즘 인스턴스 예시

제품-중립 스켈레톤을 프리즘 BP평가 4.2에 적용한 예시 구성 (7페이지) — 다른 제품의 정답 레이아웃이 아닙니다. 실물 크기는 레퍼런스 구현 참조.

1/7BP평가 종합지원자 카드 + 종합 요약 밴드 + 영역 점수 카드 3종 + 레이더 + 답변 품질 사이드
2/7검증 포인트강점/검토 2카드 + 문항별 검사 결과 리스트
3/7자기소개서 분석범례 + 문항 카드 (원문 하이라이트 · 역량 · AI 작성률)
4~6/7BP 평가 상세페이지 타이틀(첫 장만) + 대분류 밴드 + 항목 행 반복 — 분량에 따라 페이지 수 가변
7/7답변 품질 · 하드스킬답변 품질 밴드 3종 + 하드스킬 평가 + 안내사항 카드(필수)
변형 규칙 — 라이선스 · 기준 설정에 따라 달라지는 것 (변형별 별도 디자인 없음)
전형 통과 기준 = 배수지원자 카드에 「n배수 이내/이상」 fill 배지 + 「권장 기준」 캡션 표시 · 종합 요약 막대에 n배수 기준점수 링 마커(#FF006B) + 범례 추가
부적격 기준 = 점수배수 배지 대신 「권장 / 검토 필요」 배지 + 「권장 기준: n점 이상」 캡션 · 막대에 기준점수 링 없음
기준 미사용상위% outline 배지만 표시 · 합불성 배지·캡션·링 마커 전부 제거
모집단 10명 미만「상위 n%」 표현 전면 제거 — 상위% 배지, 상위 10% 마커·범례 모두 숨김 (평균 마커는 유지)
복수 라이선스BP평가가 통합 결과지의 일부로 들어가는 경우: 지원자 카드는 종합결과 페이지에만 노출되고 BP 파트는 서브 헤더로 시작 · 배수 기준 사용 불가(점수 기준만) · 페이지 번호는 통합 문서 기준 연번
변형은 요소의 표시/숨김으로만 처리한다 — 레이아웃·색·규격을 바꾸는 변형은 없다

새 제품의 결과지를 만들 때 결정할 것은 3가지뿐입니다. 그 외에는 아무것도 새로 디자인하지 않습니다.

1
테마색 1개 선정 — 지원자 카드 · 서브 밴드 전용
어두운 톤(흰 글자 대비 4.5:1 이상). 본문·칩·차트에는 절대 사용하지 않는다 — 본문 강조는 항상 #0075FF.
2
푸터 로고 + 제품명 텍스트 확정
로고 PNG를 logo/ 폴더에 추가 (표시 높이 10~14px, width auto). 제품명은 Noto Sans SemiBold 12.
3
페이지 구성 선택 — 종합(1P) / 상세(2P+) / 마지막(안내) 조합
이 문서의 컴포넌트만으로 조립. 필요한 컴포넌트가 없으면 임의 제작하지 말고 시스템에 먼저 추가한다.
신규 제품은 기존 등급 체계(3단계 서술형 · 5단계 점수형 · 합불형) 중 하나를 선택해 상속한다 · 합불 직접 표현 금지 · 이름 마스킹 필수

제품별 변형 등급 · 판정 체계

등급 체계는 디자인이 아니라 정책의 문제입니다 — 제품별 채점 로직과 결합되어 있으므로 임의로 하나로 통일하지 않습니다. 각 제품은 자신의 등급 체계를 대등하게 유지하며, 디자인 시스템은 이를 강제 환산하지 않고 그대로 담습니다. 신제품은 기존 체계 중 하나를 선택해 상속합니다 (새 체계 임의 신설 금지).
